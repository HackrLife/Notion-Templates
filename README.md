# Notion Templates

Free Notion templates by HackrLife, one folder per template. Each template lives in Notion; this repo holds what goes around it: an overview, a setup guide, a changelog and, where useful, sample data and scripts.

## Templates

| Template | What it does | Status | Get it |
| --- | --- | --- | --- |
| [Second Brain OS](templates/second-brain-os) | One Notion system for notes, projects, tasks, goals, finance, reading, hobbies and people, with a home dashboard and sample data. | Launching | Notion Marketplace link coming with the launch |

## How this repo is organised

```
templates/
  <template-slug>/
    README.md        what it does, who it is for, screenshots, the duplicate link
    guide.md         setup and day-to-day use
    CHANGELOG.md     what changed in each version
    screenshots/     images used in the README
    sample-data/     optional: the template's example rows as CSV
    scripts/         optional: code that ships with the template
```

## Adding a template

1. Build it in Notion under Template Studio, with a Start Here page and removable sample data.
2. Add `templates/<template-slug>/` with the files above and a row in the table.
3. When it is listed on the Notion Marketplace, add the link to its README and to the table.

## Updating a template

Change the template in Notion, then add an entry to its `CHANGELOG.md` and update its README if what it does has changed.
